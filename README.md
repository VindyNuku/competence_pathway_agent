# AI Competence & Learning Pathway Assistant

A small agentic AI prototype exploring personalised lifelong learning through competence gap analysis and adaptive learning pathways.

## Features

- Identifies missing competencies for an example career profile.
- Recommends learning resources and explains their relevance.
- Uses a local AI model to generate personalised learning advice.
- Updates the learning pathway as competencies are completed.
- Visualises competency profile coverage.

## Technologies

- Python
- Ollama (local language model)
- Gradio (web interface)

## Run Locally

1. Install Python, Ollama, and the required Python packages.
2. Download the Ollama model used by the application.
3. Run `python app.py`.
4. Open the local Gradio interface in your browser.

## Research Context

This prototype explores how AI-supported competence analytics and adaptive learning pathways might contribute to lifelong learning.

**Note:** This is an early-stage research demonstration using fictional learning resources and a predefined career profile. Competency coverage is not a validated assessment of career readiness.
